Liquid-filled surface

Celá plocha je
nádoba s kapalinou

Žádný disk, žádná kruhová maska. Tvar určuje container — viewport, sekce nebo karta se zaoblenými rohy. Bubliny stoupají uvnitř a hranice tvaru respektují, protože fyzika i shader používají stejnou definici.

Jako pozadí karty

Stejný engine, menší container. Velikost bublin i jejich počet se odvozují od plochy, takže karta nedostane bubliny z fullscreenu ve zmenšenině.

Auto-init

Nastaveno přes data-liquid-bubbles atribut, bez řádku JS.

Jiná paleta

Sedm stopů v configu. Celý materiál se přebarví, bubliny se přizpůsobí.

Běžná karta

Pro srovnání — efekt je opt-in per element, ne globální filtr.

Jako pozadí sekce

Vlastní instance s klidnějším nastavením — pomalejší tok, méně bublin.

Klidnější varianta

flow: 0.03, rise: 16, density: 2.4

Použití

Dva soubory, žádné závislosti.

<!-- 1. fullscreen pozadí -->
<link rel="stylesheet" href="liquid-bubbles.css">
<div class="lb lb--fixed" id="bg"></div>
<script src="liquid-bubbles.js"></script>
<script>
  LiquidBubbles.create('#bg');

  // 2. jako karta - tvar si vezme z CSS border-radius
  LiquidBubbles.create('.card', {
    bubbles: { density: 6, maxRadius: 22 },
    liquid:  { flow: 0.03 }
  });

  // 3. nebo deklarativně, bez JS
  LiquidBubbles.autoInit();
</script>
liquid-bubbles.js — WebGL, bez závislostí, respektuje prefers-reduced-motion.
